# Siamese few-shot recognition of rare viruses in TEM images

This is a research project on the public **TEM virus dataset** (Matuszewski & Sintorn 2021, Mendeley Data [10.17632/x4dwwfwtw3.3](https://doi.org/10.17632/x4dwwfwtw3.3)). It studies a Siamese (shared-weight) metric-learning encoder trained with supervised contrastive loss on the 14 benchmark classes. The 8 rare classes are added at test time as **generalised few-shot** classes, and are never used to train the encoder.

**Status (17 Oct 2026):** all experiments are finished and a first manuscript draft is written ([`paper/manuscript_draft.md`](paper/manuscript_draft.md)). See the *Notes for the authors* at the end of the draft for the open issues.

## Main results (official test split; details and CIs in the draft)

| Setting | Siamese SupCon (3 seeds) | Baseline (paper model re-trained, 1 seed) |
|---|---|---|
| 14 classes, accuracy / macro-F1 | 94.77 ± 0.18 % / 0.942 ± 0.004 | 94.53 % / 0.938 (published: 93.1 % / 0.921) |
| 22 classes, nearest class mean, macro-F1 | 0.786 ± 0.008 | 0.779 |
| 22 classes, logistic regression on frozen features (selected on validation), macro-F1 | 0.846 ± 0.012 | 0.870 |
| 1-shot rare-class mean accuracy (NCM) | **37.3 ± 2.3 %** | 30.5 % |
| 5-shot rare-class mean accuracy (NCM) | 64.7 ± 1.2 % | 68.8 % |

- **14-class difference:** Siamese vs baseline is +0.47 points, cluster-bootstrap 95 % CI [−1.29, +2.09]. The two are statistically indistinguishable.
- **Rare-class diagnosis:** the confused rare-class pairs are almost perfectly linearly separable on validation (e.g. Dengue vs Sapovirus AUC = 1.000). The rare-class errors come from the nearest-prototype rule, not the representation.

## Reproducing

1. **Set up and test.** Python 3.12, PyTorch 2.11 + CUDA 12.8 (`tem_fewshot/requirements.txt`). Run `python tests/run_tests.py`.
2. **Get the data.** `python download_data.py --out data`, then `python f0_verify_data.py --data-root data`.
3. **Run the experiments.** The full experiment queue is `tem_fewshot/run_queue.bat` (training, evaluation, analysis, comparisons); the rare-class study is `tem_fewshot/run_gfsl.bat`. The exact command lines used are in those files and in each run's `config.json`.
4. **Rebuild the numbers.** Collect results with `python collect_results.py --out report_data.json`, then regenerate the manuscript numbers with `python paper/extract_numbers.py > paper/paper_numbers.md`.

All runs used one NVIDIA RTX 3060 (12 GB).
