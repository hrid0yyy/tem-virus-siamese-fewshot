Siamese few-shot classification of TEM virus images

Metric learning on the Matuszewski & Sintorn TEM virus dataset: the paper's 14-class benchmark, the 8 rare classes the paper excluded, and unknown-virus detection. Every number below is read directly from the result files.

Findings

  1. Siamese training transfers to viruses it never saw. With 4 classes hidden from training and 5 examples per class, the trained backbone features reach 96.9% vs 86.9% for frozen ImageNet features (paired difference +10.0 ± 0.4 points). With look-alike classes hidden the gain is +4.8 ± 0.3 points.
  2. On the paper's 14-class task, Siamese ties the supervised model. Siamese backbone features: 94.95% / macro-F1 0.943. The paper's model re-trained here under the same evaluation: 94.53% / 0.938. Paired difference +0.47 points, 95% CI [-1.29, +2.09] (micrograph bootstrap), McNemar p = 0.39. The published 93.1% is lower than our re-run of the same model under this evaluation. Only one training seed finished, so run-to-run variation is not yet measured.
  3. New virus classes can be added without retraining, but a model trained on them is better. With the 8 rare classes added only as prototypes, the Siamese model reaches 89.9% accuracy and macro-F1 0.795 on all 22 classes. A cross-entropy model trained on all 22 classes (same split) reaches 93.1% and 0.897. The Siamese route is useful when new viruses appear after deployment and retraining is not possible.
  4. The 128-d projection embedding fails on new classes; the backbone features work. In the 22-class test the 128-d embedding gives macro-F1 0.684 and a rare-class mean accuracy of 41.1%, against 0.795 and 76.9% for the backbone features. The same pattern appeared in both feasibility tests.
  5. For few-shot use, supervised features are about as good as Siamese features. Using the paper model's backbone the same way, rare-class accuracy with 5 examples is 60.1% vs 59.0% for Siamese; Siamese is clearly ahead only with 1 example (35.3% vs 27.3%).
  6. The hard cases are small round viruses and the arenaviruses. Dengue is mostly predicted as Sapovirus, and Lassa partly as Guanarito. Dengue stays poor even for the model trained on it (F1 0.264), which points to the images rather than to the Siamese method.

Data and protocol

Dataset
TEM virus dataset, Matuszewski & Sintorn (2021), Mendeley Data 10.17632/x4dwwfwtw3.3 — 1,245 micrographs, 22 classes, official 256×256 patches at 1 nm/pixel (10,604 patches in train/validation/test).
Split
The official micrograph-level train / validation / test split. Training used only train, model selection and every tuning choice only validation; the test split was used only to report results.
Data checks
All per-class patch and micrograph counts equal the official listing and Table 1 of the paper (0 problems); every image readable; 0 byte-identical patches across splits; 0 training or augmented patches identical to any rotation or flip of a validation or test patch.
Siamese model
ImageNet DenseNet201 shared encoder → global pooling (1,920-d "backbone features") → MLP → 128-d L2-normalised embedding. Supervised contrastive loss (temperature 0.1) on batches of 14 classes × 4 patches drawn from different micrographs. D4 rotations/flips and ±8 px shifts; scale never changed. AdamW (backbone 5e-5, head 5e-4), cosine schedule, early stopping on validation macro-F1 of the backbone features.
Classification
Nearest class mean (cosine) with prototypes from the official train split. Rare classes are added only as prototypes from their own training patches.
Baselines
The authors' DenseNet201 classifier rebuilt exactly (Flatten → 1024 → 1024 head, 144,987,022 parameters, Adam 1e-5, batch 12, 50 epochs, their augmented training set); and a cross-entropy DenseNet201 trained on all 22 classes with class-balanced sampling.
Evaluation
Per-patch accuracy and macro-F1 as in the paper, averaged over 8 rotations/flips (TTA) for every model in this report. 95% confidence intervals resample micrographs within each class (1,000 draws); paired comparisons use the same cluster bootstrap plus an exact McNemar test.

Limitations

  • All numbers in this report average predictions over 8 rotations and flips at test time. The published 93.1% did not; our re-run of the paper's model under the same evaluation is the fair reference.
  • The choice to use backbone features instead of the 128-d embedding was informed by the feasibility tests (F2, F3), which used test patches of the hidden classes. The main runs fixed this choice before their own evaluation.
  • The 8 rare classes have 2–8 test micrographs each, so their per-class numbers are uncertain.
  • Patches from one micrograph are correlated; the micrograph bootstrap accounts for this, the McNemar test does not.
  • Hyper-parameters are reasonable defaults chosen before the runs, not tuned; all variants tried are reported.
  • The remote PC rebooted twice during the runs. Interrupted runs were restarted from scratch and kept on disk (E1_paper_densenet201_interrupted, _interrupted2); training was later made resumable.
  • Not finished when this report was generated: E1_siamese_supcon_densenet201_seed1, E1_siamese_supcon_densenet201_seed2, E6_supcon_auxce05_densenet201, E6_triplet_densenet201.
